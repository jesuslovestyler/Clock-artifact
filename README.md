# Clock Artifact

A real-time analog clock, built with Noki — Tyler's SI agent — through artifact engineering: describing what you want in plain language and getting working software back.

## What it is

- Live analog clock face with smoothly sweeping hour, minute, and second hands
- Current date, day of week, and timezone displayed below
- Light and dark themes that follow your system
- Responsive — looks great on phones and desktops

## Run it

Just open `index.html` in any browser. No build step, no dependencies. Or enable GitHub Pages on this repo to host it live.
